# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from loading and cleaning raw data to generating business insights. It includes Python-based EDA, SQL analysis, a Power BI dashboard, a detailed report, and a presentation created using Gamma.

## Dataset

The dataset contains structured business/customer-related data used to explore patterns, trends, and key performance indicators.

The data was:

* Loaded and explored using Python
* Cleaned and prepared for analysis
* Stored/analyzed using SQL
* Used to create visualizations and business insights

## Tools & Technologies

* **Python** – Data loading, cleaning, and EDA
* **Pandas & NumPy** – Data manipulation and analysis
* **Matplotlib & Seaborn** – Data visualization
* **PostgreSQL / MySQL / SQL Server** – SQL analysis
* **Power BI** – Interactive dashboard creation
* **Gamma** – Presentation/PPT creation
* **Jupyter Notebook** – Python analysis and documentation

## Project Steps

### 1. Data Loading

Loaded the dataset into Python using Pandas and reviewed its structure, columns, data types, and records.

### 2. Exploratory Data Analysis

Performed EDA to identify:

* Data distributions
* Trends and patterns
* Missing values
* Duplicate records
* Outliers
* Relationships between variables

### 3. Data Cleaning

Prepared the dataset by:

* Handling missing values
* Removing duplicates
* Correcting data types
* Treating inconsistent values
* Preparing clean data for further analysis

### 4. SQL Analysis

Imported the cleaned data into a SQL database and performed queries using PostgreSQL/MySQL/SQL Server.

Analysis included:

* Filtering and sorting
* Aggregations
* GROUP BY and HAVING
* JOIN operations
* Subqueries
* CASE statements
* Business KPI calculations

### 5. Power BI Dashboard

Created an interactive Power BI dashboard to present important KPIs, trends, comparisons, and business insights using charts, cards, tables, and filters.

### 6. Report

Prepared a report documenting the methodology, analysis, key findings, visualizations, and business recommendations.

### 7. Presentation

Created a professional project presentation using Gamma to communicate the project objectives, analysis, dashboard insights, and conclusions.

## Dashboard

The Power BI dashboard provides an interactive view of the analyzed data and allows users to explore important metrics and trends through visualizations and filters.

## Results

The project helped identify meaningful patterns and trends in the dataset and converted raw data into actionable business insights. The combined use of Python, SQL, and Power BI demonstrates an end-to-end data analytics workflow.

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Load the dataset from the project folder.
5. Run the Python cells sequentially.
6. Import the cleaned data into PostgreSQL, MySQL, or SQL Server.
7. Execute the SQL queries provided in the SQL folder.
8. Open the Power BI `.pbix` file to explore the dashboard.
9. Review the project report and Gamma presentation for detailed findings.
